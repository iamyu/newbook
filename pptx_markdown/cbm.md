# 业务能力图的应用场景3：人力消耗优化

<span style="color:#000000"> __1\.__ </span>  <span style="color:#000000"> __定位高消耗能力单元：__ </span>

<span style="color:#000000">基于业务能力图，识别出人力投入大但产出效益低的能力模块，优先作为优化重点。</span>

<span style="color:#000000"> __2\.__ </span>  <span style="color:#000000"> __流程与能力重组：__ </span>

<span style="color:#000000">整合重复能力，减少跨部门重复投入，推动能力共享和平台化建设。</span>

<span style="color:#000000"> __3\.__ </span>  <span style="color:#000000"> __推动__ </span>  <span style="color:#000000"> __IT__ </span>  <span style="color:#000000"> __自动化：__ </span>

<span style="color:#000000">针对规则明确、重复性强的能力，引入流程自动化、低代码开发及</span>  <span style="color:#000000">AI</span>  <span style="color:#000000">辅助，降低人工干预。</span>

<span style="color:#000000"> __4\.__ </span>  <span style="color:#000000"> __优化人员配置：__ </span>

<span style="color:#000000">通过能力评估调整岗位设置，实现从事务性岗位向高附加值岗位的转型。</span>

<span style="color:#000000"> __5\.__ </span>  <span style="color:#000000"> __建立持续评估体系：__ </span>

<span style="color:#000000">将人力消耗与业务价值相结合，构建滚动分析和持续优化的闭环机制</span>

高耗能点的特点如下：

业务量大

业务重复

线下手工作业为主

涉及多个角色，等待时间较长

作业效率提升空间大
