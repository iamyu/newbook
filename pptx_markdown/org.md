# 对国内外领先公司组织架构深入研究，总结对本公司运营组织架构设计的启示



  * __销售前置__
    * 销售和需求搜集紧密配合，甚至成立独立的销售子公司，对销售收入和销售质量负责
  * __产品支持服务集中__
    * 建立统一的产品支持服务团队，统一标准和服务水平
  * __专业化分工__
    * 前后线分离
    * 按照客户行业、复杂程度等标准，对价值链中的环节进行分类管理
  * __关注客户满意度和忠诚度__
    * 了解客户需求并提供相应的产品和服务
    * 不断强化与客户满意度直接关联服务，建立各自的差异化优势
  * __持续改革__
    * 国际上领先的公司仍在不断进行运营模式和组织的调整
  * 本公司组织设计中要体现销售和产品线的协同配合，做到业务开拓和产品匹配
  * 组织设计要体现“集中”和“共享”的思想
  * 本公司应该在组织设计中突出体现运营专业化分工的思想，把后台运营逐步从销售中剥离
  * 组织设计要体现围绕客户的思想，注重客户的差异化需求
  * 本公司运营组织设计在借鉴国外先进实践时，要特别关注目标企业所在行业监管特点和行业成熟度以及企业所处发展阶段，有选择的进行吸收
