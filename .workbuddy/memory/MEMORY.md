### 文章写作质量规范（2026-05-15确认）

**每次写完文章后必须自查以下5项**：

#### 1. 错别字修正
- 人名、地名、成语等必须用字准确
- 常见错误：反应→反映、做出→做出、发挥→发挥
- "的地得"用法准确区分

#### 2. 用词搭配优化
- 动宾搭配要合理（如"发现问题"而非"创造问题"）
- 修饰语与中心语要匹配
- 同义词替换避免重复

#### 3. 语句通顺
- 删除冗余词语（如"其实""可以""很""大约""左右"等口语化助词）
- 句式结构清晰，避免病句
- 逻辑连接词使用准确

#### 4. 标点规范
- 列举项用分号或顿号分隔，句末用句号
- 括号内内容简洁，括号外保留必要标点
- 破折号"——"用于解释说明
- 引号用于强调或特定术语

#### 5. 口语化书面化整改
- 删除口语词：其实、可以说、说白了、很重要、那么、这个、那个
- 删除冗余副词：很、非常、特别、相当、比较
- 删除无意义填充：也就是说、也就是说、也就是说
- 使用书面语替代口语表达
