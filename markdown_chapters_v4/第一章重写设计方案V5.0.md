### 第3节：企业DNA——决定变革成败的遗传基因（完整保留七类分型）

**定位**：完整保留Noel Tichy的七类企业分型理论，不删不减

**完整保留的七类分型**（原书第54-62行）：

1. **前瞻适应型企业**：具有前瞻性眼光，未雨绸缪，灵活调整但战略清晰
2. **随机应变型企业**：不能始终未雨绸缪，但必要时能随机应变，容易失去机会
3. **军队型企业**：少数高层领航，通过领导意志成功，风险集中在领导层
4. **消极进取型企业**：决策一致但无法实施，惰性大，基层忽视上层指令
5. **间歇型企业**：有许多优秀领导但各自为政，缺乏协调，时成时败
6. **过度膨胀型企业**：扩张超出运营负荷，管理层无法有效控制
7. **过度管理型企业**：多层管理，官僚作风，效率低下

**原书结论保留**：
- "全球1/3的企业属于前3类，是健康型企业；而后4种被视为不健康。"
- "前瞻适应型企业将是未来市场的主导者。"

**新增内容**（业务变革视角，不超过30%）：
- 企业架构如何帮助企业从"间歇型"转变为"前瞻适应型"
- DNA理论对EA设计的启示：不同DNA类型的企业，EA实施路径不同

2. **EA框架**（业务架构为主）：
   - 业务架构（主线）：业务能力、流程、组织、绩效
   - IT架构（赋能）：应用、数据、技术，支撑业务架构落地

3. **EA落地核心逻辑**（来自用户PPT）：

   - 第二步：匹配组织与权责（谁来负责干）
   - 第三步：再优化业务流程（事怎么高效干）
   - **关键**：顺序不能乱！

4. **EA价值主张**（业务变革视角）：
   - 帮助企业建立系统性变革能力
   - 降低变革失败风险（BCG：70%变革项目失败）
   - 支撑从"优秀"到"卓越"的跨越（呼应第一节卓越绩效）
